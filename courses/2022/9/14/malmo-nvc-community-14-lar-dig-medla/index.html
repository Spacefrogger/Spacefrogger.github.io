Malmö NVC Community #14 – Learn to mediate

Wednesday 14 September 2022 · 18:30–21:00

STPLN, 3 Stapelbäddsgatan, Malmö, Skåne län, 211 75, Sweden

A connection between two people isn’t always as stable as we’d like to believe. If one party doesn’t have the resources to listen, the conversation can collapse. If you’re one of three people in a conversation, you can be the one who helps your friends, employees, family, or people in public, talk with each other – if you want to.

This evening you’ll learn the basics of mediation using Nonviolent Communication (NVC). We’ll practise in a safe setting and use role-play, going through five steps:

  • Listen to party A with empathy
  • Translate A’s message
  • Convey A’s message to B
  • Make sure B has heard the message
  • Ask for B’s reaction

The steps are then repeated from B to A, and we practise doing this in a flow.

The evening is well-suited if you’re a manager, leader, mediator, couples therapist, or in some other way want to be able to support others who are struggling. Vegan, relatively low-sugar and very gluten-free fika will be available.

Prerequisites

None. If you’re an experienced NVC practitioner, you’re welcome to come and get more practice.

Cost
